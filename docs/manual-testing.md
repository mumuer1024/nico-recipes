# 用户手动测试说明

这份说明用于在浏览器中检查 Nico Recipes 的实际使用体验。打开待测站点即可，不需要安装开发工具或运行命令。以下是测试步骤与预期结果，不代表你手上的版本已经通过测试。

[返回站点说明](../README.md)

## 开始前

准备一个电脑浏览器；如有手机，再用手机重复关键步骤。先保持浏览器缩放为 100%，关闭“减少动态效果”，让普通动画测试有明确的观察条件。每组测试可记为“通过 / 未通过 / 未测”。

当前内容基线如下。以后新增菜谱或完成类型标注时，应同步更新本表及空池预期，不把正常的内容变化当作故障。

| 来源 | 菜谱数 | 目录结构 |
| --- | ---: | --- |
| 猫猫餐桌 | 3 | 直接列出菜谱，无二级分类 |
| GLP-1 高蛋白食谱 | 108 | 早餐 23、午餐 8、晚餐 59、零食 15、配菜 3 |
| Boston Cooking-School Cookbook | 1880 | 34 个章节分类 |
| 合计 | 1991 | 三个来源 |

目前五个类型池（正餐、零食、饮料、甜品、汤）均为空；“全部”及三个来源池可正常抽取。

## 1. 首页与导航

| 操作 | 预期结果 |
| --- | --- |
| 打开首页 | 显示“今天，吃点什么？”、三个来源的简介和两个主要操作 |
| 查看页面底部 | 显示“猫猫餐桌 · 高蛋白 · 1910” |
| 点击“浏览菜谱”和顶部“菜谱目录” | 均进入同一个目录页 |
| 分别点击“随便抽一个”、圆球区域和顶部“扭蛋机” | 均进入扭蛋机页，不自动抽取 |
| 从目录、扭蛋机、详情页点击左上角品牌 | 返回首页 |
| 观察首页圆球 | 有轻微、缓慢的漂浮，不遮挡文字或按钮 |

## 2. 目录折叠与详情

用新打开的页面进入目录，避免浏览器后退恢复之前的展开状态。

1. 确认三个来源最初都折叠，数量符合上表。
2. 展开猫猫餐桌，确认直接看到 3 道菜谱。
3. 不关闭猫猫餐桌，继续展开 GLP-1 和 Boston。三个来源应能同时保持展开。
4. 确认 GLP-1 按早餐、午餐、晚餐、零食、配菜排列；Boston 按章节展示。二级分类最初都折叠。
5. 连续展开 GLP-1 的早餐和午餐，再展开 Boston 的一个章节。之前打开的分类不应自动关闭。
6. 收起一个二级分类，确认其他分类不受影响；收起一个来源，确认其他来源不受影响。
7. 从三个来源各打开至少一道菜谱。应能看到菜谱标题和正文，Boston 正文保留英文。
8. 点击详情页的“菜谱目录”或“返回菜谱目录”，应回到目录。
9. 将一道详情页地址复制到新标签页，并刷新，确认仍能直接打开。

目录可能采用已有中文显示名，详情页采用原菜谱标题；两者不必逐字相同，但必须是同一道菜。可用“花毛一体”“自制牧场酱”“照烧鸡腿排”检查已有收藏地址是否仍有效；如果站点部署在子路径下，保留网址中的站点前缀。

## 3. 选择扭蛋池

| 操作 | 预期结果 |
| --- | --- |
| 新打开扭蛋机页 | 默认选中“全部”，显示 1991 道菜谱，按钮为 READY，无结果纸条 |
| 依次选择猫猫餐桌、高蛋白、1910 | 每次只有一个池被选中，数量依次为 3、108、1880 |
| 每个来源池分别抽取几次 | 纸条来源始终属于所选来源；“高蛋白”对应 GLP-1，“1910”对应 Boston |
| 切回“全部”抽取几次 | 每次产生一张有效纸条，来源可以是任意一个来源 |
| 依次选择五个空类型池 | 显示“暂时没有菜谱”提示，抽取按钮不可用，点击不出纸、不滚动 |
| 从空池切回任一非空池 | 数量恢复正确，按钮可再次抽取 |

空池按钮目前仍显示较淡的 `READY`，以空池提示和不可点击状态判断。切换池子不会自动抽取，也不一定清除上一轮纸条；已有纸条仍代表上一轮结果。

抽到重复菜谱属于正常情况。“全部”按菜谱随机，并不保证三个来源出现次数相同；Boston 菜谱最多，因此更常出现。少量手动抽样只能检查结果范围，不能证明随机概率是否均匀。

## 4. 机器视觉与一次完整抽取

1. 确认机身、顶部装饰、标题、三个槽位框和底部大按钮均完整显示。
2. 确认三个 Emoji 分别位于左、中、右槽位内，`READY` 使用站点字体并在红色按钮内居中。
3. 点击红色按钮靠近左侧的空白位置。应能触发抽取，不必点中文字。下一轮可再测试右侧空白位置。
4. 按钮应在约 100ms 内轻微下沉，文字变为 `···`。
5. 三个槽位开始滚动，并按左、中、右依次停止。滚动内容不应越过各自槽位边界。
6. 三个槽位停止后，纸条从机身下缘出现，不应盖住抽取按钮。滚动加出纸约为 1–1.5 秒。
7. 纸条显示菜谱名称、来源，以及适用时的分类，并带有“查看菜谱”提示。
8. 纸条完整出现后，按钮继续保持锁定约 1 秒，再恢复位置和 `READY`。
9. 点击纸条的文字或留白区域，都应打开对应菜谱详情。

Emoji 与菜谱没有对应关系，三个 Emoji 相同也没有特殊含义。

## 5. 防连点与冷却时间（重点）

分别进行下面三轮测试。每轮都先等按钮恢复 `READY`，再点击一次启动抽取。

| 连点时机 | 操作 | 预期结果 |
| --- | --- | --- |
| Emoji 滚动期间 | 快速连点大按钮约 10 次，然后松手 | 只有当前一轮抽取，不重启动画、不出现多张纸条 |
| 纸条正在出现时 | 快速连点大按钮，然后松手 | 当前纸条继续正常出现，结果不被中途替换 |
| 纸条已完整出现、按钮还未恢复时 | 在这一秒内继续连点，然后松手 | 按钮仍锁定，不提前开始下一轮 |

每轮松手后至少再观察 3 秒：即使按钮恢复 `READY`，也不应自行补抽。只有恢复后新的一次点击才能启动下一轮。注意在恢复前停止连点，以免把恢复后的新点击误认为排队触发。

再启动一轮，尝试在抽取过程中切换池子：选项应暂时不可操作，当前结果不应改变。下一次有效抽取会替换旧纸条，不会堆积成历史列表。

冷却应从纸条**完整出现**后计算，不能从首次点击或滚轮停止时提前计算。肉眼只能检查约一秒的体验；如怀疑时序问题，可录屏记录，精确的 1000ms 边界需结合自动化验证。

## 6. 手机、窗口缩放与对齐

在电脑上缩窄窗口，并分别尝试 80%、125%、200% 浏览器缩放；有手机时，再检查竖屏与横屏。每种情况下观察待机状态，并至少抽取一次。

- 三个 Emoji 始终位于对应槽位内，不随缩放错位；滚动期间也不溢出。
- `READY` 或 `···` 始终居中于大按钮，点击范围跟随按钮位置。
- 纸条始终连接在机身下缘，长菜名和来源能换行，不被截断。
- 页面不出现横向溢出，导航、池选项和纸条都能操作。
- 常见桌面尺寸（如 1280×720）和手机竖屏（如 390×844）下，首页和扭蛋待机页以单屏为目标。
- 极矮屏幕、较大缩放或较长结果纸条允许纵向滚动；应能滚动到完整内容，不为强行单屏而裁切。

手机上的 Emoji 外观可能与电脑不同，重点检查位置、裁切与操作。

## 7. 减少动态效果

在设备系统设置中开启“减少动态效果”（名称可能不同；部分系统提供关闭动画的开关），然后重新打开页面。

1. 首页圆球不再明显漂浮。
2. 点击非空池的 `READY`：直接显示最终 Emoji 和菜谱纸条，不播放明显滚动、按键下沉或出纸动画。
3. 结果出现后仍锁定约 1 秒，期间连点无效；恢复后才可再次抽取。
4. 点击结果纸条，仍可正常阅读菜谱。
5. 关闭该设置并重新打开页面，普通动画恢复。

如果设备支持在页面打开期间切换设置，也可在滚动时开启减少动态效果：当前动画应尽快结束，显示完整结果，不应卡住按钮。

## 8. 键盘与无脚本浏览（补充）

只使用键盘检查以下操作：

- 用 Tab 移动到导航、目录标题、菜谱链接和抽取按钮时，能看清焦点。
- 用 Enter 或空格展开目录；多个分类仍能同时保持展开。
- 在池选项组内用方向键切换选择，每次只选中一个。
- 用 Enter 或空格激活 `READY`，一轮结束后可移到纸条并打开详情。

如果熟悉浏览器的 JavaScript 开关，可临时关闭后重新打开站点：目录折叠和菜谱阅读仍可使用；扭蛋机应显示开启 JavaScript 的说明和目录入口，抽取按钮不可用。测完后恢复设置。不熟悉该开关时可将此项记为“未测”。
