# The Boston Cooking-School Cook Book

从 Fannie Merritt Farmer《The Boston Cooking-School Cook Book》（1910，Project Gutenberg eBook #65061）中抽出的单道菜谱合集。

## 内容

- 菜谱数量：1880
- 来源章节：第 III 章至第 XXXVI 章（饮料到水果蜜饯）
- 未收入：第 I–II 章食物与烹调原理、第 XXXVII–XXXVIII 章家事提示与菜单、术语表、索引，以及全大写分类标题、食材说明等非菜谱段落（56 条）

每道菜谱一个 Markdown 文件，含标题、章节、页码、配料表（原书有独立配料行或表格时）和做法。原文为英文，未翻译。

## 目录结构

```text
boston-cooking-school-cookbook/
  moc/               说明与索引（不作为单道菜谱）
    README.md        本说明
    index.md         英文原名索引
    index.zh-CN.md   已有中文名称对照索引（菜谱正文仍为英文）
  recipes/           按章节存放的单道菜谱
```

## 使用

菜谱按章节放在本合集的 `recipes/` 下；从本说明所在目录访问为 `../recipes/`。单道菜谱的路径、元数据和正文保持原样。
